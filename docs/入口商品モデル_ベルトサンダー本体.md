# ベルトサンダー本体を「入口商品」として再投入すべきか

作成日: 2026-08-22 / 判定: **本体単体の限界利益がプラスになる仕入値が取れない限り見送り**

---

## 1. 結論

**「本体を薄利〜赤字で入れ、替えベルトのリピートで回収する」モデルは、この規格・この販売量では成立しない。**

理由は3つ。

1. **消耗品のリピート周期が長すぎる。** 104-0050 は「50本セット」で売っている。DIY・小規模整備の使い方で50本を使い切るのは年単位で、買い直しは年1回がいいところ。回収式の分子が伸びない。
2. **消耗品の市場そのものが小さく、すでに取り切っている。** 3ヶ月販売数59個（月19.7個）。Yahoo!自然順位1〜3位、楽天3位、広告費ほぼゼロ。露出が足りなくて売れていないのではなく、需要の天井が低い。本体で母数を増やしても、増える幅が小さい。
3. **回収に必要な本数に届かない。** 本体1台が1年で生む替えベルトの限界利益は約440円（同梱率40%・年1回買い直し・自店継続率50%の前提）。本体を1台あたり500円赤字にすると、回収には1.02セット/台が必要で、実力0.90セットでは届かない。

ただし裏返すと、**本体単体の限界利益がプラスなら、普通の商品として出す価値はある**（そのとき替えベルトの引き上げは「おまけ」であって、判断の根拠にはならない）。判断の順番を逆にしないこと。

## 3. 計算（`entry_product_model.py` の出力）

```
--- 本体の限界利益（売価4,980円・送料650円・Yahoo変動費24.3%） ---
  原価 2,000円 → 限界利益 1,120円 （22.5%）
  原価 2,500円 → 限界利益   620円 （12.4%）
  原価 3,000円 → 限界利益   120円 （ 2.4%）

--- 本体1台が生む消耗品（同梱率40%・年1回買い直し・自店継続率50%）---
  年間 0.90セット/台 → 消耗品の限界利益 440円/台/年

--- 本体が赤字だった場合、回収に必要な消耗品セット数 ---
  本体   -200円/台 → 必要 0.41セット/台 （実力 0.90）… 達成可能
  本体   -500円/台 → 必要 1.02セット/台 （実力 0.90）… 達成不可
  本体 -1,000円/台 → 必要 2.05セット/台 （実力 0.90）… 達成不可

--- 月次インパクト（本体の限界利益 +920円/台の場合）---
  本体  3台/月 → 月  4,079円 （0.6%）
  本体  5台/月 → 月  6,798円 （0.9%）
  本体 10台/月 → 月 13,597円 （1.9%）
  本体 20台/月 → 月 27,194円 （3.8%）
```

替えベルトの月販19.7個から逆算すると、本体が現実的に売れるのは月3〜5台。
そのとき店舗全体への寄与は**月4,000〜7,000円**。
目標「利益率+3pt = 月+107,000円」に対して**4〜6%**にしかならない。
一方で初期不良・返品・保証対応・在庫（本体は単価が高く在庫が重い）のリスクを新規に背負う。

**割に合わない。**

## 4. 同じ目的（客単価アップ・閑散期対策）に、もっと効く手

### 4-1. 番手アソートのセットSKU（最優先）

2026-08-10 の受注に実例がある——同一顧客が **#120×50本 + #80×50本 を同時購入して2,736円**。
番手を複数買う需要は実在している。それを商品側で用意していないだけ。

- 「#40/#60/#80/#120 各50本 4番手セット」を1SKUで出す
- 客単価 1,393円 → 4,000〜5,000円
- **送料185円が1回で済む**ので、限界利益率が単品より跳ねる（4個バラ売りなら送料740円、セットなら185円で最大555円の差）
- 在庫も原価も既にある。仕入も撮影も新規リスクもゼロ

本体再投入（月+4,000〜7,000円・リスクあり）より、こちらのほうが確実に大きい。

### 4-2. 楽天側の順位を上げる

同じ商品で楽天は1,980円・限界利益766円。Yahoo!の370円の**2.07倍**。
楽天は自然3位・access18人。ここを1〜2位に上げるほうが、1個あたり2倍稼げる。
（実利益ダッシュボードの重点3「楽天を額のレバーとして伸ばす」と同じ方向）

### 4-3. 回遊バナー「研磨・仕上げグループ」

既にジムニー・園芸・クリップで回している回遊バナーの枠組みをそのまま使う。
- 104-0050 替えベルト / 584 ミニルーター / 8-001 エアーポリッシャー / 618 内張りはがし

根拠: 104-0050 の実流入語に「**ルーター 工具 6**」「**内装剥がし 工具 6**」が入っている。
すでに隣接需要が同じページに来ている＝グルーピングの妥当性がデータで裏取りできている。
本体を仕入れずに客単価を上げられる。

## 5. 逆算型リサーチ軸として一般化する

「利益の取れる消耗品 → その消耗品を使う本体を探す」は軸として有効。ただし**7つ全部YESでないと成立しない**。
ベルトサンダーは 1・2 で落ちる。

| # | 項目 | 判定基準 | ベルトサンダー |
|---|---|---|---|
| 1 | リピート周期 | 1回の購入を4ヶ月以内に使い切る量か | ✗ 50本セット＝年1回未満 |
| 2 | 本体の需要 | 本体KWの検索需要が消耗品KWの3倍以上か | ✗ 消耗品の主要語で月7流入。母数が小さい |
| 3 | 本体の採算 | 本体単体の限界利益がプラスか | ？ 仕入次第（原価3,000円で+120円） |
| 4 | 消耗品の採算 | 消耗品の限界利益が1個400円以上か | △ 489円→10月424円 |
| 5 | 受け皿の順位 | 消耗品が主要語3位以内か | ✓ Yahoo!1〜3位・楽天3位 |
| 6 | 物流 | 本体の送料が売価の15%以下か | ✓ 4,980円に対し宅急便コンパクト650円=13% |
| 7 | 故障リスク | 非電動または単純機構か | ✓ エアー工具＝モーターなし |

**1と2が本質的な足切り。** 「消耗品で儲かっている」だけでは足りず、
- 消耗品が**速く減る**こと（＝小分けで売れること）
- 本体側の検索需要が消耗品より**大きい**こと（＝入口として機能すること）

この2つが揃って初めて、本体を薄利で入れる意味が出る。

チェックは `python3 entry_product_model.py --screen` で出力できる。
候補が見つかったら `run_belt_sander()` を雛形に数字を差し替えて回収期間を出す。

### 5-1. 既存商品でこの軸を回すなら

自社で既に「本体」を持っているのは 584 ミニルーター（3ヶ月65個・楽天アクセス2位・月155件の入口）と 8-001 エアーポリッシャー。
**方向を逆にして「本体はあるが消耗品を売っていない」を埋めるほうが、条件1・2をクリアしやすい。**
ミニルーター用ビット・研磨用バフ・ペーパーは、本体の需要が大きく（条件2 ✓）、小分けで速く減る（条件1 ✓）。
次のリサーチはここから当たるのが筋がいい。

## 6. もし本体を出すなら（条件付きのGO）

見送りが結論だが、進めるなら順序を守ること。

1. **先に仕入値を確定する。** 4,980円で売って限界利益がプラスになる原価（≒3,000円未満）で取れるか。取れなければそこで終了。赤字入口は選択肢に入れない。
2. **102-001 の過去実績を管理表で確認する。**（商品別総累計表 / 在庫管理シート）。当時の販売数と利益が分かれば、上のシミュレーションの「月3〜5台」を実測で置き換えられる。
3. **テストは小ロット（10〜20台）。** 本体在庫は単価が高く、滞留すると原価率に効く。
4. **判定指標は本体の売上ではなく、`替えベルトの月販個数`**。19.7個/月がベースライン。本体投入から3ヶ月で25個/月を超えなければ入口として機能していない＝撤退。
5. 4-1のセットSKUを**先に**やる。本体より安く速く、効果も大きい。
